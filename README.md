# 金融工作台 PWA

基于 iPhone 的金融仪表盘，深色金融终端风格，可「添加到主屏幕」当原生 App 用。

## 指标

- 恐贪指数（综合 + 6 个子指标：动量、宽度、强度、Put/Call、垃圾债、波动率、避险需求）
- 涨跌家数、两融余额、股指期货前 20 席位多空持仓
- 申万一级 31 行业：当日涨跌 + PE-TTM 历史分位轨道

## 数据来源（浏览器直连，无需后端）

- 腾讯 `qt.gtimg.cn` —— 申万一级行业当日涨跌
- 东方财富 push2 / datacenter —— 指数行情、全 A 涨跌家数、融资融券
- 乐咕乐股 —— 行业 PE 历史分位（静态快照）

数据更新策略：打开页面自动拉取一次；切回前台且超过 30 分钟未更新才再拉；不做盘中轮询。各数据源独立成败，失败降级到内置静态快照。

## 运行

纯静态站点，直接用任意静态服务器托管，或将 `index.html` / `sw.js` / `manifest.json` / `icon.svg` 部署为 PWA 即可。
